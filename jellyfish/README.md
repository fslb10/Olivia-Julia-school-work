# Asian Freshwater Jellyfish, Canada

A Grade 6 research website aligned with the seven sections of the supplied invasive species poster assignment.

Open `index.html` directly, or visit `/jellyfish/` on this repository's GitHub Pages site once Pages deployment succeeds.

Includes an embedded species photograph, original labelled diagrams, selectable Canadian location examples, life-form explanations, a food-web explorer, two YouTube embeds with direct links, glossary, printable guide, and a browser-local checklist. No login or backend is required. Videos and external source links need internet access.

The site distinguishes established observations from possible ecological impacts. It does not claim that Canadian fish population losses have been demonstrated. Sources, video creators, and photograph licensing are credited in the website.

Validation: JavaScript syntax, internal anchors, image alternative text, and 30 DOM/interaction checks passed. Browser rendering and full YouTube playback were not verified in the build environment.
